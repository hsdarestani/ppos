GOOGLE MAPS IMPORT

Excel/CSV خروجی Google Maps را مستقیم بده

ستون‌هایی مثل name / title / category / phone / full_address / website / rating / reviews / place_id / latitude / longitude / google_maps_url خودکار تشخیص داده می‌شوند.

اگر هر فایل مربوط به یک سرچ مشخص مثل «سالن زیبایی تهران» است، صنف پیش‌فرض را انتخاب کن؛ این دقیق‌ترین حالت است. اگر فایل چندصنفی باشد، موتور category را به یکی از ۳۰ vertical مپ می‌کند. شماره موبایل وارد SMS Queue می‌شود و تلفن ثابت مستقیم در Call Desk می‌ماند. Place ID هم برای جلوگیری از import تکراری ذخیره می‌شود.
RAW DATABASE INGEST

Excel/CSV خام بانک مشاغل

ستون‌های فارسی مثل «نام کسب و کار / صنف / موبایل / تلفن / آدرس / شهر / نام مسئول» خودکار تشخیص داده می‌شوند.

اگر صنف را خالی بگذاری، موتور از متن «نوع صنف» آن را به یکی از ۳۰ vertical مپ می‌کند. موبایل برای SMS و تلفن ثابت برای Call Queue نگه داشته می‌شود.
